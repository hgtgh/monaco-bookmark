# monaco-bookmark

Monaco Editor (VS Code's editor) in a bookmark. A lightweight editor in your browser.

## Features

- **Language**: Auto-detected. Click to search and select another language.
- **Wrap**: Toggle line wrapping.
- **Preview**: Live Markdown preview, synced with scrolling. Unavailable in diff mode.
- **Diff**: Compare your text (right) with an older version (left).

## Shortcuts

| Shortcut | Action |
|---|---|
| Cmd+K / F1 | Open the command palette |
| Cmd+S | Download as `untitled.<extension>` |

Use Ctrl instead of Cmd on non-macOS systems.

**Your text isn't saved.** Closing the page discards it (after confirmation).
